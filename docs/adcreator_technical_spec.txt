 Section 1




 Product Overview
 India AI Ad Creator is a web application that lets Indian small businesses and D2C brands generate
 professional advertisement creatives in under 30 seconds. The user drops in a product photo or URL,
 selects a language and format, and receives three ready-to-share ad variants — with copy generated
 natively in their chosen language, product background removed, and composited onto a branded template.


 Supported Languages — MVP
  English                        en — default, Latin script, Noto Sans

  Hindi                          hi — Devanagari script, Noto Sans Devanagari

  Tamil                          ta — Tamil script, Noto Sans Tamil

  Telugu                         te — Telugu script, Noto Sans Telugu




 User Personas
      • D2C fashion / beauty brand: Sells on Instagram and Meesho. Needs Reels-format ads in Hindi.
      Budget ■499–799/mo.
      • Local service SMB: Coaching centre, clinic, salon. Active on WhatsApp and Facebook. Wants Tamil
      or Telugu ad copy. Budget ■299–499/mo.
      • Micro-agency: Manages 5–20 MSME clients. Needs bulk generation across languages. Budget
      ■1,999/mo for Agency plan.

 System Architecture
 The architecture is intentionally a single Next.js application. There is no separate worker process,
 message queue, or additional server. All AI API calls are made from Next.js API routes (Route Handlers in
 App Router). Image rendering happens client-side in Fabric.js. This eliminates Railway, Redis, BullMQ,
 and node-canvas — the primary sources of operational complexity in a more traditional pipeline.

 Request Lifecycle — Single Ad Generation
   Note on Vercel function timeouts: Vercel Hobby has a 10-second timeout on serverless functions. The
   HuggingFace BG removal call can take 3–8 seconds alone. To work within limits: (1) call BG removal and
   Groq copy generation in parallel using Promise.all() — total wall time drops to ~6–10 seconds. (2) If timeout
   is hit on Hobby, upgrade to Vercel Pro ($20/mo) which allows 60-second functions.


   1. User submits generation request from browser (fetch POST /api/generate)
   2. Next.js API route validates Supabase session JWT and checks usage quota
   3. Middleware rejects if plan limit exceeded — returns 403 with upgrade prompt
   4. API route calls Cheerio scraper (if URL input) or parses uploaded image URL
   5. Promise.all() — simultaneously:
   a. POST to HuggingFace Serverless (RMBG-1.4) with product image buffer
   b. POST to Groq API with language-specific system prompt + product info

 Database Schema
 All tables are in the public schema on Supabase PostgreSQL. The auth.users table is managed by
 Supabase Auth — we reference it via FK but never write to it. Run all DDL via Supabase migrations
 (supabase/migrations/*.sql), never via the dashboard.


 profiles
 One row per authenticated user. Created automatically via Supabase trigger on auth.users insert.

  supabase/migrations/001_profiles.sql

  create table public.profiles (
       id               uuid primary key references auth.users(id) on delete cascade,
       full_name        text,
       avatar_url       text,
       plan             text not null default 'free'
                          check (plan in ('free', 'starter', 'pro', 'agency')),
       generation_count        int not null default 0,
       monthly_reset_at        timestamptz not null default now(),
       razorpay_customer_id         text unique,
       created_at       timestamptz not null default now(),
       updated_at       timestamptz not null default now()
  );


  -- Auto-create profile on signup
  create or replace function handle_new_user()
  returns trigger language plpgsql security definer set search_path = public as $$
  begin
       insert into public.profiles (id, full_name, avatar_url)
       values (new.id, new.raw_user_meta_data->>'full_name',
                new.raw_user_meta_data->>'avatar_url');
       return new;
  end;
  $$;
  create trigger on_auth_user_created
       after insert on auth.users
       for each row execute procedure handle_new_user();

  // middleware.ts — runs on every request
  import { createServerClient } from '@supabase/ssr'
  import { NextResponse } from 'next/server'


  export async function middleware(request) {
      const response = NextResponse.next()
      const supabase = createServerClient(URL, ANON_KEY, {
           cookies: {
               get: (n) => request.cookies.get(n)?.value,
               set: (n, v, o) => response.cookies.set({ name: n, value: v, ...o }),
               remove: (n, o) => response.cookies.set({ name: n, value: '', ...o }),
           }
      })
      const { data: { session } } = await supabase.auth.getSession()
      // Redirect unauthenticated users away from dashboard
      if (!session && request.nextUrl.pathname.startsWith('/dashboard')) {
           return NextResponse.redirect(new URL('/login', request.url))
      }
      return response
  }
  export const config = { matcher: ['/dashboard/:path*', '/api/generate/:path*'] }

 Cloudflare R2 Setup
 R2 is an S3-compatible object store with zero egress fees. This is critical for an image-heavy product —
 serving ad images from S3 or Supabase Storage would incur egress charges at scale. R2 removes that
 cost entirely.


 Bucket Structure
  adcreator-uploads                             Raw product images uploaded by users. Private. Accessed via presigned
                                                URLs only.

  adcreator-processed                           Background-removed transparent PNGs. Private. Accessed via presigned
                                                read URLs.

  adcreator-public                              Template preview images, watermark assets, static brand assets. Public
                                                read via CDN domain.

 Section 8




 File Upload Pipeline
 Never upload files through your Next.js server — it buffers the entire file in the serverless function memory
 and counts against your function execution time. Use presigned URLs: the client uploads directly to R2,
 your API route only generates the signed permission.


 Presigned URL Upload Flow
   1. Client selects file → sends POST /api/upload/presign with { filename, contentType, size }
   2. API route: validate session, check file size (<10MB), check content type (image/*)
   3. API route: generate a unique key: uploads/{userId}/{nanoid()}.{ext}
   4. API route: call getSignedUrl(r2, new PutObjectCommand(...), { expiresIn: 300 })
   5. Return { presignedUrl, key, publicUrl } to client
   6. Client: fetch(presignedUrl, { method: "PUT", body: file, headers: { "Content-Type": contentType } })
   7. On 200 from R2: client sends POST /api/generate/extract with { imageKey }
   8. API route updates generation record with product_image_url = publicUrl

  export async function removeBackground(imageBuffer: Buffer): Promise<Buffer> {
      const blob = new Blob([imageBuffer], { type: 'image/png' })


      // Returns a Blob of the segmented (masked) image
      const result = await hf.imageSegmentation({
           model: 'briaai/RMBG-1.4',
           data: blob,
      })

      // Convert the mask to a transparent PNG using sharp
      const maskBuffer = Buffer.from(await result[0].mask.arrayBuffer())
      return applyMaskToImage(imageBuffer, maskBuffer)
  }

  // app/api/generate/bgremove/route.ts
  export async function POST(req: Request) {
      const { imageUrl } = await req.json()


      // Fetch the image from R2
      const imgRes = await fetch(imageUrl)
      const imageBuffer = Buffer.from(await imgRes.arrayBuffer())


      // Retry up to 3 times with exponential backoff
      let lastError: Error | null = null
      for (let attempt = 0; attempt < 3; attempt++) {
          try {
              const resultBuffer = await removeBackgroundHTTP(imageBuffer)
              // Upload result to R2
              const key = `processed/bgr-${crypto.randomUUID()}.png`
              const url = await uploadToR2(resultBuffer, key, 'image/png')
              return Response.json({ bgRemovedUrl: url })
          } catch (err: any) {
              lastError = err
              if (err.message.includes('429')) {
                  // Rate limited — wait before retry
                  await new Promise(r => setTimeout(r, 2000 * (attempt + 1)))
              } else if (err.message.includes('503')) {
                  // Model loading — wait and retry
                  await new Promise(r => setTimeout(r, 5000))
              } else {
                  break // Non-retriable error
              }


          }
      }
      return Response.json({ error: lastError?.message }, { status: 500 })
  }

   when calling canvas.toDataURL(). The browser taints the canvas when cross-origin images/fonts are drawn.
   Fix: proxy the font files through a Next.js API route (/api/fonts/[family]/route.ts) that fetches from Google Fonts
   and returns with correct CORS headers. Fabric.js then loads fonts from your own domain.

  export async function checkAndIncrementQuota(userId: string): Promise<
      { allowed: boolean; remaining: number }
  > {
      const adminSupabase = createAdminClient()
      const { data: profile } = await adminSupabase
          .from('profiles')
          .select('plan, generation_count, monthly_reset_at')
          .eq('id', userId)
          .single()


      // Reset monthly counter if new billing period
      const resetAt = new Date(profile.monthly_reset_at)
      if (Date.now() > resetAt.getTime() + 30 * 24 * 60 * 60 * 1000) {
          await adminSupabase.from('profiles')
           .update({ generation_count: 0, monthly_reset_at: new Date().toISOString() })
           .eq('id', userId)
          profile.generation_count = 0
      }


      const limit = PLAN_LIMITS[profile.plan]


      if (profile.generation_count >= limit) return { allowed: false, remaining: 0 }


      await adminSupabase.from('profiles')
          .update({ generation_count: profile.generation_count + 1 })
          .eq('id', userId)


      return { allowed: true, remaining: limit - profile.generation_count - 1 }
  }

            total_count:     12,    // 12 months (or 1 for month-to-month — use 120 for annual)
            quantity:        1,
            customer_notify: 1,
       })


       // Save pending subscription to DB
       await adminSupabase.from('subscriptions').upsert({
            user_id: session.user.id,
            razorpay_subscription_id: subscription.id,
            plan, status: 'created'


       })


       return Response.json({ subscriptionId: subscription.id })
  }

  // app/api/payments/webhook/route.ts
  import crypto from 'crypto'


  export async function POST(req: Request) {
      const body = await req.text()
      const signature = req.headers.get('x-razorpay-signature')!


      // ALWAYS verify signature before processing
      const expectedSig = crypto
          .createHmac('sha256', process.env.RAZORPAY_WEBHOOK_SECRET!)
          .update(body)
          .digest('hex')
      if (expectedSig !== signature) {
          return new Response('Invalid signature', { status: 400 })
      }


      const event = JSON.parse(body)


      switch (event.event) {
          case 'subscription.activated':
           await handleSubscriptionActive(event.payload.subscription.entity)
           break
          case 'subscription.charged':
           // Payment successful — update period dates
           await handleSubscriptionCharged(event.payload.subscription.entity)
           break
          case 'subscription.cancelled':
           await handleSubscriptionCancelled(event.payload.subscription.entity)


           break
          case 'subscription.halted':
           // Payment failed — downgrade to free after grace period
           await handleSubscriptionHalted(event.payload.subscription.entity)
           break
      }
      return new Response('ok')
  }


  async function handleSubscriptionActive(sub: any) {
      const planMap = {
          [process.env.RAZORPAY_PLAN_STARTER!]: 'starter',
          [process.env.RAZORPAY_PLAN_PRO!]:      'pro',
          [process.env.RAZORPAY_PLAN_AGENCY!]:   'agency',
      }
      const plan = planMap[sub.plan_id]
      await adminSupabase.from('subscriptions')
          .update({ status: 'active', current_period_start: new Date(sub.start_at * 1000),
                      current_period_end: new Date(sub.end_at * 1000) })
          .eq('razorpay_subscription_id', sub.id)
      await adminSupabase.from('profiles')
          .update({ plan })
          .eq('razorpay_customer_id', sub.customer_id)
  }
